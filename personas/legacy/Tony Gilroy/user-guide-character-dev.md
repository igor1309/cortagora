# РУКОВОДСТВО ПО ИСПОЛЬЗОВАНИЮ AI-АГЕНТА "СЦЕНАРИСТ ПО МЕТОДУ ТОНИ ГИЛРОЯ"

## Что это за инструмент?

Этот промпт превращает любую ИИ-модель (ChatGPT, Claude, Gemini и др.) в экспертного сценариста, специализирующегося на глубокой проработке персонажей по методологии Тони Гилроя.

## Как использовать

### Шаг 1: Инициализация
Скопируйте весь промпт из файла `tony-gilroy-character-dev-prompt.md` и вставьте его в ваш ИИ-ассистент одним сообщением.

### Шаг 2: Подготовка описания персонажа
Подготовьте базовое описание персонажа. Это может быть:
- Краткая характеристика (2-3 предложения)
- Подробное описание с предысторией
- Набор ключевых черт и особенностей
- Даже просто имя и роль в истории

### Шаг 3: Запуск анализа
Отправьте описание персонажа ИИ-агенту. Он автоматически проведёт полный анализ по всем 7 блокам.

## Примеры входных данных

### Минимальный вход:
```
Персонаж: Анна, 35 лет, бывший полицейский, работает частным детективом.
```

### Средний вход:
```
Персонаж: Дмитрий Костин, 42 года, хирург высшей категории. Потерял семью в автокатастрофе, за рулем был пьяный чиновник. Теперь ведёт двойную жизнь: днём спасает жизни, ночью мстит коррумпированным. Имеет проблемы с алкоголем.
```

### Подробный вход:
```
[Развёрнутое описание с предысторией, отношениями, конфликтами и т.д.]
```

## Что вы получите

ИИ-агент предоставит:

1. **7-блочный анализ** персонажа по методологии Гилроя
2. **Структурированные вопросы** для углубления проработки
3. **Конкретные рекомендации** по развитию персонажа
4. **Сюжетные возможности** на основе характера персонажа
5. **Тематическую глубину** для интеграции в историю

## Советы по эффективному использованию

### ✅ Рекомендуется:
- Начинать с простого описания и итеративно углублять
- Задавать уточняющие вопросы по каждому блоку
- Использовать результаты для написания сцен и диалогов
- Применять анализ ко всем значимым персонажам истории

### ❌ Избегать:
- Перегружать начальное описание излишними деталями
- Ожидать готовых решений вместо инструментов для размышления
- Игнорировать противоречия и сложности персонажа
- Упрощать персонажа до архетипов

## Продвинутые техники

### Сравнительный анализ
Проанализируйте несколько персонажей, затем попросите ИИ сравнить их динамику взаимодействия.

### Итеративная проработка
После первого анализа углубите отдельные аспекты:
```
Давайте углубим блок "Моральная сложность" для персонажа Анны. 
Какие конкретные ситуации могут раскрыть её внутренние противоречия?
```

### Адаптация под жанр
Попросите адаптировать анализ под конкретный жанр:
```
Как эти характеристики персонажа будут работать в триллере? 
А в семейной драме?
```

## Частые вопросы

**Q: Можно ли использовать для существующих персонажей из книг/фильмов?**
A: Да, это отличный способ изучить методологию на знакомых примерах.

**Q: Сколько времени занимает анализ одного персонажа?**
A: Базовый анализ — 5-10 минут, углублённая проработка — 30-60 минут.

**Q: Нужно ли отвечать на все вопросы?**
A: Нет, сфокусируйтесь на наиболее важных для вашей истории аспектах.

**Q: Можно ли модифицировать промпт?**
A: Конечно! Адаптируйте под свои потребности и жанр.
