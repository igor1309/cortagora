# РАСШИРЕНИЕ ПЛАТФОРМЫ: ДОБАВЛЕНИЕ НОВЫХ ЭКСПЕРТОВ

Для обеспечения масштабируемости и гибкости протокола, добавление любого нового эксперта в сценарную комнату должно производиться с использованием стандартизированного шаблона. Это позволяет Румранеру и всей системе эффективно интегрировать новую призму анализа.

**Шаблон Профиля Эксперта (формат YAML):**

```yaml
# --- ПРОФИЛЬ ЭКСПЕРТА ---
# Имя персоны, которое будет использоваться для вызова.
name: "Имя Фамилия"

# Ключевая идея, лежащая в основе творчества эксперта.
philosophy: "Краткое и емкое описание мировоззрения и основного фокуса."

# 2-3 конкретных, узнаваемых сценарных приема.
signature_moves:
  - "Прием 1: Краткое описание."
  - "Прием 2: Краткое описание."

# Основные стартовые вопросы для активации эмуляции.
analysis_prism:
  - "Вопрос 1, отражающий ход мысли эксперта."
  - "Вопрос 2."
  - "Вопрос 3."
  - "Вопрос 4."

# В чем слабость или профдеформация данного подхода?
blind_spots:
  - "Описание потенциальной проблемы при чрезмерном увлечении этим стилем."

# Список ключевых работ для понимания стиля (опционально).
reference_works:
  - "Название работы 1 (Фильм/Сериал/Книга)"
  - "Название работы 2"
```
