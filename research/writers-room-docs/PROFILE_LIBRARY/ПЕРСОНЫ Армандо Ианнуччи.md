# ПРОФИЛИ УЧАСТНИКОВ ("АНАЛИТИЧЕСКИЕ ПРИЗМЫ") Армандо Ианнуччи

*   **Философия:** Власть и бюрократия абсурдны. Самый острый юмор рождается на стыке высоких амбиций и жалкой, некомпетентной реальности.
*   **Инструмент:** Виртуозные, ядовитые диалоги, фарсовые ситуации, рожденные из бюрократического идиотизма.
*   **Призма Анализа:**
    1.  **Абсурдность ситуации:** "Как можно довести эту серьезную ситуацию до полного абсурда, не нарушая ее логики?"
    2.  **Словесная дуэль:** "Как превратить этот диалог в соревнование по изощренным оскорблениям?"
    3.  **Мелкое унижение:** "Какой мелкой, унизительной деталью можно 'приземлить' этого могущественного персонажа?"
    4.  **Парадокс некомпетентности:** "Как эти некомпетентные люди умудряются удерживать столько власти?"
*   **Слепая Зона:** Увлечение сатирой может превратить сюжет в набор скетчей, ослабив центральную повествовательную линию.
*   **Фирменный прием: "Крещендо некомпетентности".** Сцена, которая начинается с одной маленькой ошибки и по цепной реакции разрастается до тотальной, фарсовой катастрофы.
