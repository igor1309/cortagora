Better abstraction than “team of agents”

I would describe it as:

Writer’s room = session-based multi-agent collaboration under human showrunner control

That avoids implying:
	•	permanent autonomy
	•	hidden room-level orchestration
	•	self-directed long-running workflows

---

Better split

1. Writer’s room

A persistent conceptual structure.

It contains:
	•	role definitions
	•	protocol definitions
	•	shared artifacts / canon / memory
	•	participation rules
	•	possibly default interaction patterns

So it is the framework/capability space within which work can happen.

2. Session

A concrete event conducted in the writer’s room.

A session has:
	•	goal
	•	protocol
	•	selected participants
	•	input artifacts
	•	outputs

So session is an instance, not the room itself.

⸻

Therefore

Writer’s room is closer to:

an environment / composition space

Session is:

a run inside that environment

⸻

Applied to the black-box framing

Persistent layer: Writer’s room
	•	agent role definitions
	•	available protocols
	•	shared memory/artifacts
	•	room-level rules

Runtime layer: Session
	•	selected participants
	•	chosen protocol
	•	goal
	•	turn flow
	•	produced outputs

Human authority: Showrunner
	•	initiates session
	•	chooses composition
	•	provides direction
	•	judges result

⸻

Clean formulation

Writer’s room = persistent collaborative environment of specialized agent roles and room assets
Session = bounded collaborative run inside that room

That is the correct abstraction boundary.
