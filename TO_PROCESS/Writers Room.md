# Writers Room

Используй поиск **CORE_PROTOCOL** в чатах с ИИ
Есть дополнения по специализации персон и workflow

## Habitants (personas)
Определяются описанием персоны (есть шаблон, включает особый взгляд/подход, сильные/слабые стороны).
Специализации:
  - Методолог(и) // Пропп, Кэмпбелл, др
  - Сценарист(ы)
  - Продюсер(ы)
  - Маркетолог(и)
  - Критик(и)
  - Исследователь

## Modalities (brainstorm, create, analyze,...)
Определяются протоколами работы

Комбинация участников и модальности позволяет гибко создавать команды для выполнения конкретной задачи. Под повторяющиеся задачи, например структурный анализ, создаются протоколы.￼
