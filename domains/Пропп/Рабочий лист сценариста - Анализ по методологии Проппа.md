## Анализ персонажей

### Распределение ролей Проппа
| Роль Проппа | Персонаж | Описание функции |
|-------------|----------|------------------|
| **Герой** | | Главный протагонист, движущая сила истории |
| **Антагонист** | | Создает основной конфликт |
| **Даритель** | | Предоставляет помощь/инструменты |
| **Помощник** | | Поддерживает героя |
| **Искомый персонаж** | | Цель героя (может быть человеком или объектом) |
| **Отправитель** | | Инициирует путешествие героя |
| **Ложный герой** | | Конкурирует с главным героем |
