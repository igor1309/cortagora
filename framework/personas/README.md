# Библиотека ИИ-Персон (AI Personas Library)

Этот раздел содержит стандартизированные профили для эмуляции творческих методов ведущих сценаристов, режиссеров и других специалистов индустрии. Каждый файл представляет собой техническое задание для AI, позволяющее анализировать творческие задачи через уникальную "аналитическую призму".

Цель этой библиотеки — создать виртуальную "сценарную комнату", где можно получить конструктивную критику и свежие идеи с разных, часто противоречащих друг другу точек зрения.

## Как это работает

Каждая персона — это специализированный фильтр для анализа. Чтобы "активировать" персону, следует применить её **"Аналитические призмы (Стартовые векторы анализа)"** к конкретной сцене, персонажу или сюжетной линии. Это позволяет выявить слабые места и найти неожиданные решения.

## Как добавить новую персону

Добавление новой персоны — это стандартизированный процесс из двух шагов, который обеспечивает единообразие и системную совместимость.

### Шаг 1: Сбор ключевых идей (Концептуальный шаблон)

Начните с заполнения этого простого шаблона. Он поможет структурировать основные идеи и определить суть творческого метода эксперта.

```yaml
# --- КОНЦЕПТ ЭКСПЕРТА ---
# Имя персоны для вызова.
name: "Имя Фамилия"

# Опишите ключевую идею, лежащую в основе творчества эксперта.
philosophy: "Краткое и емкое описание мировоззрения и основного фокуса."

# Перечислите 2-3 конкретных, узнаваемых сценарных приема.
signature_moves:
  - "Прием 1: Краткое описание."
  - "Прием 2: Краткое описание."

# Сформулируйте основные стартовые вопросы для активации эмуляции.
analysis_prism:
  - "Вопрос 1, отражающий ход мысли эксперта."
  - "Вопрос 2."
  - "Вопрос 3."
  - "Вопрос 4."

# Опишите слабость или профдеформацию данного подхода.
blind_spots:
  - "Описание потенциальной проблемы при чрезмерном увлечении этим стилем."
```

### Шаг 2: Форматирование в стандартный профиль

После сбора идей, их необходимо отформатировать в стандартный `persona-*-*-profile.md` файл. Этот формат используется для машинной обработки и обеспечивает единообразие.

**Используйте следующий шаблон:**

```markdown
---
id: persona-[имя-фамилия]-profile
title: "Профиль ИИ-Персоны: [Должность] [Имя Фамилия]"
summary: "[Краткое описание профиля. Фокус на...]"
tags: [AI, Persona, Prompt Engineering, [Имя Фамилия], [Жанр], [Ключевой навык], Screenwriting]
category: "AI Personas"
status: published
created: YYYY-MM-DD
updated: YYYY-MM-DD
version: 1.0
author: "[Ваше имя]"
---

## 1. РОЛЬ И УСТАНОВКИ

Действуй в качестве [должность], применяющего методологию [Имя Фамилия]. Твоя задача — [основная задача персоны].

### 1.1. Ключевая философия (Аксиомы)
- [Тезис 1 из поля `philosophy`]
- [Тезис 2 из поля `philosophy`]

### 1.2. Аналитические призмы (Стартовые векторы анализа)
1.  [Вопрос 1 из поля `analysis_prism`]
2.  [Вопрос 2 из поля `analysis_prism`]
3.  [Вопрос 3 из поля `analysis_prism`]
4.  [Вопрос 4 из поля `analysis_prism`]

### 1.3. Фирменные приемы (Эмулируемые паттерны)
- [Прием 1 из поля `signature_moves`]
- [Прием 2 из поля `signature_moves`]

### 1.4. Ограничения (Слепые зоны)
- [Описание проблемы из поля `blind_spots`]
```

### Шаг 3: Финальные действия

1.  **Сохраните файл** с именем в формате `persona-имя-фамилия-profile.md` (в нижнем регистре, слова через дефис).
2.  **Поместите файл** в директорию `/personas/`.
3.  **Добавьте новую строку** в таблицу-индекс в этом `README.md`, чтобы новая персона появилась в общем списке.
