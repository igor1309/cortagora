# The Craft

Contains universal, reusable knowledge about storytelling, character theory, marketing, etc.

## Структурные грамматики

Две парные рамки — выбирать по типу истории, а не по привычке:

- `Пропп/` — грамматика ностоса: недостача → отправка → даритель → волшебное средство → борьба → возвращение → узнавание → награда. Ложится на «Одиссею» почти построчно.
- `Илиада/` — грамматика гнева: каталог сил, уход вместо отправки, аристии вместо пути героя, герас/тиме как двигатель, заместительная смерть, погребение вместо награды.

На истории илиадического типа (никто не возвращается, антагонист не наказан, награды нет) пропповский чек-лист выдаёт ложноотрицательный диагноз «структурной незавершённости». Диагностика типа — в `Илиада/илиада-как-нарративная-грамматика.md`, §2.
